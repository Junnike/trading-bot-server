Grow light planners

Two tools for the same job: PPFD, DLI and spectrum for a room or a shelf. Both are a single HTML file that runs in the browser with no server.

Grow Light Planner (new, version 5, built with Claude Code in November 2026, 109 KB, Estonian and English) mixes any number of lamp types, places them by dragging, reads IES and LDT files, models wall reflections per axis and shelves with side strips, has 15 plant presets with DLI, ePAR and McCree weighting, four colour themes and PNG, CSV and JSON export. Open it.

Kasvuvalguse kalkulaator V3.1 (older, built with Claude earlier in 2026, 99 KB, Estonian only) handles one lamp type at a time in rows and columns, reads IES and LDT, uses one reflectance for all walls, and prints a calculation report with project, client and author fields. Open it.

Which is better: the new one for planning and for checking offers, since it handles mixed lamps, shelves and per-axis reflections and gives a grid you can send to a client. The old one's only advantage is the printable report, which is the next feature planned for the new one.
